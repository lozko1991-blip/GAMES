# Глобальні інструкції для AI (Kronos Games)

Два проєкти у цьому репозиторії:

- `battle-for-truhanov/` — файтинг на чистому HTML5 Canvas (файтинг «Битва за Труханів»).
- `penalty-master/` — симулятор пенальті «Kronos Football» + міні-ігри (basketball, matrix run).

Обидва — vanilla JS без збірки, без npm, без ES6 modules. Користувач пише українською — відповідай стисло українською.

## Обов'язковий робочий процес

1. **Перед будь-якою роботою** — короткий план дій (1–5 пунктів) повідом користувачу, потім виконуй.
2. **Спочатку читай документацію** проєкту (`docs/BATTLE_FOR_TRUHANOV.md`, `docs/PENALTY_MASTER.md`) та AGENTS.md відповідного проєкту, перш ніж змінювати код.
3. **Перевіряй, а не гадай** — якщо не впевнений у назві функції/змінної, знайди її grep-ом або прочитай файл. Ніколи не вигадуй функції, яких не існує.
4. **Перевірка після змін**:
   - battle-for-truhanov: обов'язково `node validate.js` у папці проєкту → очікуй `SUCCESS: All scripts loaded in the correct order!` і код 0. Жодних помилок — zero-error tolerance.
   - penalty-master: синтаксична перевірка кожного зміненого файлу `node --check src/файл.js` (проєкт не має validate.js).
5. **Мінімальні зміни** — прав тільки те, що потрібно для задачі. Нічого «зайвого», не реформатуй увесь файл, не чіпай нерелевантний код.
6. **Нічого не ламати** — в історії проєктів уже були випадки пошкодження файлів (заміна index.html з бекапу). Працюй обережно, перевіряй результат після кожної зміни.
7. Після зміни логіки battle-for-truhanov додай запис у `battle-for-truhanov/AI_CHANGELOG.md`.

## Файли, які НЕ можна читати або змінювати

Заборонено інструментами (opencode.json): `battle-for-truhanov/assets.js` (11.5 МБ Base64) та `battle-for-truhanov/assets/` (PNG).

- Вся інформація про них (персонажі, рівні, магазин) вже описана в `docs/BATTLE_FOR_TRUHANOV.md`.
- Якщо потрібно змінити асети — спитай користувача; він підкаже, як зробити без прямої правки.

## Архітектурні правила (обидва проєкти)

- Порядок завантаження скриптів у `index.html` — критичний (залежності через глобальні змінні). Нові скрипти додавай тільки в кінець списку, якщо вони залежать від старих.
- Заборонено ES6 `import/export` — тільки глобальні змінні/функції.
- Якщо клас потрібен одразу на старті, оголошуй `let ІМ'Я;` у ранньому скрипті, а ініціалізуй у кінці пізнього (див. `let AI_ENGINE` у battle).
- LocalStorage: battle використовує ключі `truhanov_*`, penalty — `pm_*` (через обгортку `safeStorage` у penalty). Зберігай цю конвенцію.

## Структура репозиторію

- `docs/` — технічна документація: `BATTLE_FOR_TRUHANOV.md`, `PENALTY_MASTER.md`.
- `battle-for-truhanov/` — код гри + `instruction.md` (опис для людей), `.agents/AGENTS.md`, `AI_CHANGELOG.md`, `validate.js`.
- `penalty-master/` — код гри + `.agents/AGENTS.md`.
- `opencode.json` — правила доступу AI до файлів.
